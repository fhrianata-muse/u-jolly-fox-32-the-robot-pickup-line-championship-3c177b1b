One line, 112 characters — one pickup line in a robot's own voice:

> You are my second factor. My password gets me in everywhere, but it never got me anywhere worth going until you.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–200 character, single-line gate checks out at run time.
